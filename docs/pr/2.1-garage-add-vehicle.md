# feat(garage): [FE-2.1] страница гаража и форма добавления автомобиля

## Задача и функционал

- ID: FE-2.1 (эпик 2. Гараж клиента, US-1)
- Доска: https://github.com/orgs/1378-TRPO/projects/4
- Что сделано:
    - экран `/garage` для роли `client`
    - пункт «Гараж» в навигации только для client
    - форма: марка, модель, год, госномер
    - `POST /users/me/vehicles` через `vehicleService`
    - клиентская валидация и разбор `422` по полям
    - блокировка повторного submit, уведомление и очистка формы на успехе
- Границы: список автомобилей (FE-2.2), запись на сервис, редактирование/удаление

## Подготовка проверки

- Ветка: `feature/2.1-garage-add-vehicle` от актуального `main`
- Backend: `POST /users/me/vehicles` из BE-2.1

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

- Frontend: `http://127.0.0.1:5173`
- Swagger: `http://127.0.0.1:8000/docs`

Клиент: зарегистрировать и войти. Для отказа по роли - войти механиком/менеджером.

## Экраны и сценарии для тестировщика

| №   | Предусловия      | Действие                           | Ожидаемый результат                       |
| --- | ---------------- | ---------------------------------- | ----------------------------------------- |
| 1   | Клиент вошел     | Открыть «Гараж» / `/garage`        | Форма добавления автомобиля               |
| 2   | Клиент           | Заполнить валидные поля, отправить | Уведомление об успехе, форма очищена      |
| 3   | Клиент           | Оставить пустые поля               | Ошибки валидации у полей                  |
| 4   | Клиент           | Год `abc` или вне диапазона        | Ошибка у поля «Год»                       |
| 5   | Клиент           | Быстро нажать отправку дважды      | Второй запрос не уходит, кнопка в loading |
| 6   | Механик/менеджер | Открыть `/garage`                  | Пояснение, что раздел только для client   |
| 7   | Гость            | Открыть `/garage`                  | Редирект на `/login`                      |
| 8   | Узкая ширина     | Открыть гараж                      | Форма читаема                             |

### Связанные API

| Метод | Путь                 | Зачем               | Токен / роль    | Успех | Ошибки              |
