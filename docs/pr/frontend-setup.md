# chore: подготовить основу frontend

## Функционал

Техническая задача перед экранами бизнес-логики: Vite + React + TypeScript,
Mantine UI, роутинг, JWT-клиент к auth API, пастельная тема Fog & Clay,
линтеры, CI и шаблон PR для тестировщика.

Реализованы каркасные экраны:

- `/login` - вход
- `/register` - регистрация клиента
- `/` - главная после входа
- `/profile` - профиль клиента (имя, телефон, email)

## Подготовка проверки

Ветка: `chore/frontend-setup`. Node.js 22+.

Нужен запущенный backend на `http://127.0.0.1:8000` (миграции применены).

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5173`.
В dev Vite проксирует `/auth`, `/users`, `/health` на backend.
`VITE_API_BASE_URL` можно оставить пустым.

Тестовый клиент: зарегистрируйте новый email через UI или Swagger.

## Экраны и сценарии

| №   | Предусловия           | Действие                                    | Ожидаемый результат            |
| --- | --------------------- | ------------------------------------------- | ------------------------------ |
| 1   | Backend запущен       | Открыть `/login`                            | Форма входа, бренд RPS         |
| 2   | Нет аккаунта          | Регистрация валидным email/паролем          | Вход выполнен, редирект на `/` |
| 3   | Email занят           | Повторная регистрация                       | Ошибка про занятый email       |
| 4   | Клиент вошел          | Открыть `/profile`, сохранить имя и телефон | Данные сохраняются             |
| 5   | Без токена            | Открыть `/`                                 | Редирект на `/login`           |
| 6   | Узкая ширина (~390px) | Открыть кабинет                             | Бургер-меню, формы читаемы     |

## Связанные API

| Метод | Путь             | Зачем              | Токен         | Успех | Ошибки                     |
| ----- | ---------------- | ------------------ | ------------- | ----- | -------------------------- |
| POST  | `/auth/register` | Регистрация        | Нет           | `201` | `409`, `422`               |
| POST  | `/auth/login`    | JWT                | Нет           | `200` | `401`, `422`               |
| GET   | `/auth/me`       | Роль на главной    | Bearer        | `200` | `401`                      |
| GET   | `/users/me`      | Профиль            | Bearer client | `200` | `401`, `403`               |
| PATCH | `/users/me`      | Сохранение профиля | Bearer client | `200` | `401`, `403`, `409`, `422` |
