# feat(catalog): [FE-3.2] управление каталогом менеджером

## Задача и функционал

- ID: FE-3.2 (эпик 3. Каталог услуг, US-07)
- Доска: https://github.com/orgs/1378-TRPO/projects/4
- Что сделано:
    - страница `/manager/services` только для `manager`
    - пункт «Каталог» в навигации менеджера
    - список активных и неактивных услуг
    - создание и редактирование `name`, `description`, `price`, `duration_minutes`
    - подтверждение и soft-delete через `DELETE /manager/services/{id}`
    - инвалидация manager-list и клиентского `GET /services`
- База: ветка включает FE-3.1
- Границы: запись на услугу, фильтры/поиск

## Подготовка проверки

- Ветка: `feature/3.2-manager-services`
- Backend: manager CRUD из BE-3.2

```powershell
npm install
npm run dev
```

Менеджер: создать через CLI бека и войти.

## Экраны и сценарии для тестировщика

| №   | Предусловия    | Действие                           | Ожидаемый результат                           |
| --- | -------------- | ---------------------------------- | --------------------------------------------- |
| 1   | Менеджер вошел | Открыть «Каталог»                  | Список услуг и кнопка добавить                |
| 2   | Менеджер       | Создать услугу                     | Появляется в списке как активная              |
| 3   | Менеджер       | Изменить услугу, обновить страницу | Значения сохранены                            |
| 4   | Менеджер       | Удалить → Отмена                   | Запрос не уходит, услуга активна              |
| 5   | Менеджер       | Удалить → подтвердить              | Статус «Неактивна», в клиентском каталоге нет |
| 6   | Клиент/механик | Открыть `/manager/services`        | Отказ по роли                                 |

### Связанные API

| Метод  | Путь                     | Зачем       | Роль    | Успех | Ошибки                     |
| ------ | ------------------------ | ----------- | ------- | ----- | -------------------------- |
| GET    | `/manager/services`      | Список всех | manager | `200` | `401`, `403`               |
| POST   | `/manager/services`      | Создать     | manager | `201` | `401`, `403`, `422`        |
| PATCH  | `/manager/services/{id}` | Изменить    | manager | `200` | `401`, `403`, `404`, `422` |
| DELETE | `/manager/services/{id}` | Soft-delete | manager | `200` | `401`, `403`, `404`        |
