# feat(garage): [FE-2.2] список автомобилей и состояния страницы

## Задача и функционал

- ID: FE-2.2 (эпик 2. Гараж клиента, US-1)
- Доска: https://github.com/orgs/1378-TRPO/projects/4
- Что сделано:
    - `GET /users/me/vehicles` через `vehicleService.getVehicles`
    - TanStack Query hook `useVehicles` и ключ `queryKeys.vehicles`
    - на `/garage`: loading, error+retry, empty state, список с маркой/моделью/годом/госномером
    - после успешного добавления список инвалидируется без перезагрузки
- База: ветка включает FE-2.1 (форма добавления)
- Границы: edit/delete, запись на сервис

## Подготовка проверки

- Ветка: `feature/2.2-garage-list` от `main` + merge FE-2.1
- Backend: `GET/POST /users/me/vehicles` из BE-2.1/BE-2.2

```powershell
npm install
npm run dev
```

## Экраны и сценарии для тестировщика

| №   | Предусловия           | Действие            | Ожидаемый результат                         |
| --- | --------------------- | ------------------- | ------------------------------------------- |
| 1   | Новый клиент          | Открыть `/garage`   | Empty state и форма добавления              |
| 2   | Клиент с машинами     | Открыть `/garage`   | Список с маркой, моделью, годом, госномером |
| 3   | Клиент                | Добавить автомобиль | Список обновляется без reload               |
| 4   | API списка недоступен | Открыть `/garage`   | Ошибка и кнопка «Повторить»                 |
| 5   | Два разных клиента    | Сравнить списки     | Чужие автомобили не видны                   |
| 6   | Узкая ширина          | Открыть гараж       | Список и форма читаемы                      |

### Связанные API

| Метод | Путь                 | Зачем             | Токен / роль    | Успех | Ошибки              |
| ----- | -------------------- | ----------------- | --------------- | ----- | ------------------- |
