# feat(users): [1.3] профиль клиента - имя, телефон и email

## Задача и функционал

- ID: 1.3
- Эпик: 1. Пользователи и доступ
- Оценка: 1 SP
- Что сделано:
    - экран `/profile` для роли `client`
    - `GET /users/me` и `PATCH /users/me`
    - валидация имени, телефона и email по правилам API
    - частичное сохранение только измененных полей
    - очистка имени/телефона пустым значением (`null` в запросе)
    - guard: не-client видит пояснение, пункта меню у них нет
- Границы: пароль и роль не меняются; подтверждение email не входит в MVP

## Подготовка проверки

- Ветка: `feature/1.3-client-profile` от актуального `main`
- Backend с миграцией `0002`, JWT настроен

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

- Frontend: `http://127.0.0.1:5173`
- Swagger: `http://127.0.0.1:8000/docs`

Клиент: зарегистрировать и войти. Для `403` - войти механиком/менеджером (CLI на беке).

## Экраны и сценарии для тестировщика

| №   | Предусловия              | Действие                          | Ожидаемый результат                                           |
| --- | ------------------------ | --------------------------------- | ------------------------------------------------------------- |
| 1   | Клиент вошел             | Открыть `/profile`                | Форма с именем, телефоном, email                              |
| 2   | Новый клиент             | Поля имя/телефон пустые           | Можно сохранить имя и телефон                                 |
| 3   | Клиент                   | Очистить имя и телефон, сохранить | Поля очищены (`null` на API)                                  |
| 4   | Клиент                   | Телефон `+79991234567`            | Успех                                                         |
| 5   | Клиент                   | Телефон со скобками/пробелами     | Ошибка валидации                                              |
| 6   | Клиент                   | Сменить email на свободный        | Успех; JWT `sub` = id, сессия жива; вход дальше с новым email |
| 7   | Другой клиент существует | Занять его email                  | Ошибка: email занят                                           |
| 8   | Без изменений            | Нажать сохранить                  | Кнопка неактивна / нет пустого PATCH                          |
| 9   | Механик/менеджер         | Открыть `/profile`                | Пояснение, что профиль только для client                      |
| 10  | Узкая ширина             | Открыть профиль                   | Форма читаема                                                 |

### Связанные API

| Метод | Путь        | Зачем            | Токен / роль    | Успех | Ошибки                     |
| ----- | ----------- | ---------------- | --------------- | ----- | -------------------------- |
| GET   | `/users/me` | Загрузка профиля | Bearer `client` | `200` | `401`, `403`               |
| PATCH | `/users/me` | Сохранение       | Bearer `client` | `200` | `401`, `403`, `409`, `422` |
